# Security policy

## Report a problem privately

Do not open a public issue, pull request, or discussion for a security problem.

Send an email to **support@tabulaspeech.com**. Use the subject line `Security`.

GitHub private vulnerability reporting is not on for this repository now. The maintainers can turn it on later. If they do, this file will say so.

## What to include

- What the problem is, and what an attacker can do with it.
- The app and the file or screen (for example: Tabula Debate, Ballot tab; Speech Events, `events/js/ballot.js`).
- Steps to make the problem occur again. A small test file or proof of concept helps.
- The browser, its version, and the device.
- If you want credit, the name to use.

Do not send real student data, real API keys, or other people's personal data. Use made-up data.

## What we do

- We acknowledge your report within 3 business days.
- We send a status update within 10 business days.
- We tell you when a fix is ready. Please give us time to fix the problem before you make it public.

## Scope

In scope (code in this repository):

- Tabula Debate (`index.html`, `js/`, `logic/`, `formats/`, `core/`).
- Tabula Speech Events (`events/`).
- File formats and import and export code in both apps.
- The local helper `bridge.mjs`.

Out of scope for this repository: the hosted server and the web console. Their code is not in this repository. You can still report problems with them through the same email address.

## Bug bounty

There is no bug bounty. We do not pay for reports.

## Safe harbor

If you do research in good faith, follow this policy, do not access or change other people's data, and do not disrupt the service, we will not take legal action against you for that research.
