## Same flow, two judges

The last two speeches are about one stock issue: significance (whether the problem the plan fixes is big enough). The neg ran no disadvantage. "->" means "so".

```
2NR:
  Significance: plan helps only
    500 people a year -> too
    small to matter
2AR:
  Yes, 500 people. But no DA ->
    no cost. A small gain is
    still a gain
```

In words: the neg says the plan helps only 500 people a year, so it is too small to matter. The aff agrees that it is 500 people, but says there is no disadvantage, so a small gain with no cost is still worth it.

Assume the judge decides that the neg won significance: 500 people is too small to count as a big problem.

How would a stock issues judge and a policymaker judge most likely decide?

- [ ] Both vote aff, because the aff spoke last
- [x] The stock issues judge votes neg, because the aff must win every stock issue; the policymaker votes aff, because a small gain with no cost is still a net gain
- [ ] The stock issues judge votes aff, because significance is not a stock issue; the policymaker votes neg, because the gain is small
- [ ] Both vote neg, because 500 people is a small number

**Why:** A stock issues judge needs the aff to win each stock issue, and significance is one of them. If the neg wins it, the aff loses. A policymaker weighs costs and benefits. With no disadvantage, the plan has a small benefit and no cost, so it is still better than the status quo. Few judges fit one type exactly, so a real judge may mix the two.

## The blank slate

The neg says: "The judge should decide this round on fairness first." The aff never answers this.

What does a tabula rasa ("blank slate") judge most likely do?

- [x] Decide the round on fairness first, because the neg argued it and the aff did not answer
- [ ] Ignore the fairness point, because a blank slate judge has no views about fairness
- [ ] Use the judge's own favorite way to decide
- [ ] Vote aff, because the neg told the judge what to do

**Why:** A tabula rasa judge tries to come in with no fixed views and lets the debaters decide what matters. When one team says how to decide and the other team does not answer, this judge usually goes along. Many of these judges still keep some limits, for example on safety.

## Default or debate?

A judge's paradigm says: "If no one argues it, I give presumption to the neg." In this round, both teams spend time arguing about who should get presumption.

What should the judge do?

- [ ] Use the default from the paradigm, because it was written before the round
- [x] Decide the teams' argument about presumption first, and use the default only if no one argued the point
- [ ] Give presumption to the team the judge likes more
- [ ] Skip presumption, because the teams disagree about it

**Why:** A default is what the judge does when no one argues the point. Here the teams did argue it, so the judge decides that debate from the flow. Voting on a default after the teams argued against it is a common judge mistake.

## The lay judge

Your judge is a parent with no debate background.

What usually helps a team with this judge? Pick all that apply.

- [x] Slow down to a moderate pace
- [x] Explain terms in plain words
- [x] Make fewer, better arguments
- [ ] Make as many arguments as you can, as fast as you can
- [ ] Use debate shorthand, because it saves time

**Why:** Lay judges usually want clear speaking, a moderate pace, plain words and a story that makes sense. Fast speech and shorthand make the round harder to follow. Convincing a real person is a skill debate is meant to teach.
