## Find the drop

You flow this on the DA sheet.

```
1NC              2AC
DA: Spending
U: budget        1. N/U: big
   tight now        bill already
                    passed
L: plan costs    (no answer)
   $50B
I: school        2. Case
   programs cut     outweighs
```

In words: the 1NC read uniqueness, a link and an impact. The 2AC answered the uniqueness line and the impact line. The 2AC said nothing about the link: that the plan costs fifty billion dollars.

Which part of the DA did the 2AC drop?

- [ ] The uniqueness
- [x] The link
- [ ] The impact
- [ ] Nothing was dropped

**Why:** Read across each row. The link row has an empty space in the 2AC column. That empty space is a drop. Lining up answers next to the arguments they answer makes drops easy to see.

## What a drop means

The neg made an argument with a clear reason. The aff never answered it. In the 2NR, the neg says: "They dropped it."

How do most judges treat this argument?

- [x] As true, because it had a reason and no answer
- [ ] As false, because the aff did not talk about it
- [ ] As a reason to stop the round
- [ ] As worth nothing until the judge checks the evidence

**Why:** An argument with no answer is called a drop or a concession. Most judges treat a dropped argument as true, if it came with a reason. The judge still decides how much it matters in the round.

## Why line up answers

A new judge asks why the flow puts each answer on the same row as the argument it answers.

What is the main reason?

- [ ] It makes the notes look neat
- [x] It shows which arguments were answered and which were dropped
- [ ] It saves paper
- [ ] It tells you which team spoke faster

**Why:** When each answer sits next to its argument, an argument with no answer shows as an empty space. A messy flow that is lined up is more useful than a neat flow that is not.

## What to write

A speaker says: "Their plan costs a lot of money, so the law will force cuts to school programs, and children will lose services."

What should you write on your flow?

- [ ] Every word the speaker said
- [x] The claim and the reason in a few words, such as "plan costs $ -> forced cuts -> kids lose services"
- [ ] Only the word "DA"
- [ ] Nothing, because the speech document has it

**Why:** You cannot write every word, so do not try. Write the claim and the reason in a few words. The reason (the "because") is what wins rebuttals. The speech document has the cards, but not all of the explanation.
