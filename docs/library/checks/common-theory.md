## All fifty states

The plan has the federal government set a new safety rule for drinking water. The 1NC reads this counterplan.

```
1NC  CP: all 50 states set the
     same water rule, at the
     same time
     Net benefit: DA
```

In words: the counterplan has all fifty states set the same rule at the same time. It has a disadvantage as its net benefit (a reason the counterplan alone is better).

Which theory argument fits best for the aff, and why?

- [ ] PICs bad, because the counterplan leaves out one part of the plan
- [x] Uniform fifty-state fiat bad, because, the aff argues, no real decision-maker can make all fifty states act
- [ ] Severance perms bad, because the counterplan drops part of the plan
- [ ] International fiat bad, because the counterplan uses another country

**Why:** The counterplan fiats (imagines passed) fifty separate governments acting the same way. The aff's usual claim is that no real decision-maker can do that, and the aff cannot use evidence about states that would refuse. The neg's usual answer is that federal versus state action is a core topic question. Judges differ, and many reject the counterplan, not the team.

## All but one part

The plan builds new clinics in every region of the country. The 1NC reads this counterplan.

```
1NC  CP: build the clinics in
     every region except one
     Net benefit: DA in that
     region
```

In words: the counterplan does the whole plan except in one region. Its net benefit is a disadvantage about that one region.

Which theory argument fits best for the aff, and why?

- [x] PICs bad, because the counterplan takes almost all of the plan and leaves out one part
- [ ] Consult counterplans bad, because the counterplan asks another party first
- [ ] Multiple actor fiat bad, because the counterplan uses many governments
- [ ] Intrinsic perms bad, because the counterplan adds something new

**Why:** A plan-inclusive counterplan (PIC) does most of the plan but leaves out one part. The aff's usual claim is that PICs steal the aff's ground and give the neg options with no limit. The neg's usual answer is that PICs test every part of the plan. A common middle rule allows PICs when the neg has evidence about the part it cuts.

## Ask first

The plan has our government send aid to a region after floods. The 1NC reads this counterplan.

```
1NC  CP: ask an ally first; send
     aid only if it agrees
     Net benefit: ally ties
```

In words: the counterplan asks an ally first, and sends the aid only if the ally agrees. Its net benefit is better ties with the ally.

Which theory argument fits best for the aff, and why?

- [ ] International fiat bad, because the counterplan has another country send the aid
- [x] Consult counterplans bad, because, the aff argues, the counterplan does the whole plan and wins only on a small benefit from the process
- [ ] PICs bad, because the counterplan leaves out one region
- [ ] Multiple actor fiat bad, because many governments act at once

**Why:** A consult counterplan does the plan, but asks another party first. The aff's usual claim is that it does not compete: it does the whole plan and wins only on a small net benefit tied to the process. The neg's usual answer is that real decisions do involve asking allies. Many judges reject the counterplan, not the team, and some look mostly at competition.

## Another nation acts

The plan has our government fund clean energy research. The 1NC reads this counterplan.

```
1NC  CP: another nation's gov
     funds the same research
     Net benefit: DA
```

In words: the counterplan has another nation's government fund the same research. Its net benefit is a disadvantage.

Which theory argument fits best for the aff, and why?

- [ ] Uniform fifty-state fiat bad, because many states act at once
- [ ] Severance perms bad, because the aff's perm drops part of the plan
- [x] International fiat bad, because, the aff argues, the resolution asks what our government should do, and our decision-maker cannot choose for another nation
- [ ] Floating PIKs bad, because the alternative could include the plan

**Why:** The counterplan fiats another country's government. The aff's usual claim is that the resolution is about our government, and a domestic decision-maker cannot choose for another nation. The neg's usual answer is that comparing the plan with what other nations could do is real policy analysis. Judges differ: some accept it by default, and others are more skeptical.
