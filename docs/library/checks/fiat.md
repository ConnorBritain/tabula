## "They would never pass it"

The aff's plan has the government pay for free school meals. The neg says: "Congress would never vote for this. It costs too much."

How do most judges treat this answer?

- [ ] As a strong solvency answer, because the plan cannot work if it never passes
- [x] As an answer fiat sets aside, because the round is about whether the plan should pass
- [ ] As a disadvantage, because it is about money
- [ ] As a reason to stop the round

**Why:** Fiat lets the aff say, "Imagine the plan passes." So "it would never pass" is not a reason to vote neg for most judges. Some teams argue that fiat is imaginary, and some judges prefer real-world prediction, so read the judge's paradigm. A better neg answer is that the plan would not work, or that it would cause harm.

## Does fiat answer this?

The same plan pays for free school meals. The neg says: "Even after the plan passes, schools have no kitchen staff. Most students will still get no meals."

What kind of answer is this?

- [ ] A "would never pass" answer, which fiat sets aside
- [x] A solvency answer, which fiat does not set aside
- [ ] A counterplan
- [ ] Not an argument, because the plan is fiated

**Why:** This answer accepts that the plan passes. It says the plan will not work. That is a solvency argument. Fiat gets the plan passed, but it does not make the plan work. The aff still must prove solvency.

## The aff's reply

The neg says the plan will not work because the program has too little money. The aff answers: "Fiat means our plan works."

Is the aff's answer right?

- [ ] Yes, because fiat means the plan does what the aff says
- [x] No, because fiat passes the plan but does not prove it works
- [ ] Yes, but only if the aff spoke last
- [ ] No, because the aff cannot use fiat at all

**Why:** Fiat gets the plan passed. It does not make the plan perfect. "Too little money" is a solvency argument about whether the plan works. The aff must answer it with reasons or evidence, for example that the plan text gives enough money.

## Which answers still count?

A plan pays for new bus routes. The neg makes four answers.

Which answers are still fair under fiat? Pick all that apply.

- [x] "The buses will run empty, so the plan solves nothing."
- [x] "The plan costs money that would go to roads, so roads get worse."
- [ ] "The city council would vote the plan down."
- [x] "The buses break down a lot, so the plan works badly."

**Why:** Fiat only sets aside the question of whether the plan would pass. The council vote is that question, so most judges do not count it. "Runs empty" and "breaks down" say the plan would not work well. Those are solvency answers. "Roads get worse" says the plan causes harm. That is a disadvantage. Fiat does not stop either kind.
