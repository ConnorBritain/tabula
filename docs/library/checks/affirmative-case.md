## A smaller problem

The aff reads this case in the 1AC. "(Analyst 21)" is an invented card: author and year.

```
1AC  Adv 1: Safe bridges
  H: 1 in 5 bridges unsafe
     now (Analyst 21)
  I: bridge falls -> deaths
  Plan: fed gov funds
     bridge repair
  Solv: funds fix most
     bridges in 5 yrs
     (Expert 22)
```

In words: the harm is that one in five bridges is unsafe now. The impact is that a bridge can fall and people die. The plan is that the federal government funds bridge repair. Solvency says the funds fix most bridges in five years.

The neg says: "Their number is too high. Only 1 in 50 bridges is unsafe." Which part of the case does this attack hit?

- [ ] The plan
- [x] The harm
- [ ] Solvency

**Why:** The neg says the problem is smaller than the aff says. That is harm defense. It does not say the plan is wrong or that the plan fails. It says there is less of a problem to fix.

## Not enough workers

The aff reads this case in the 1AC.

```
1AC  Adv 1: Safe bridges
  H: 1 in 5 bridges unsafe
     now (Analyst 21)
  Plan: fed gov funds
     bridge repair
  Solv: funds fix most
     bridges in 5 yrs
     (Expert 22)
```

In words: the harm is that one in five bridges is unsafe now. The plan is that the federal government funds bridge repair. Solvency says the funds fix most bridges in five years.

The neg says: "There are not enough trained workers to do the repairs. Money alone will not fix the bridges." Which part of the case does this attack hit?

- [ ] The plan
- [ ] The harm
- [x] Solvency

**Why:** Solvency is proof that the plan works. The neg agrees the bridges are unsafe, but says the plan will not fix them. That is a solvency attack.

## Off the topic

The topic this year is about schools. The aff's plan says: "The federal government should fund bridge repair."

The neg says: "Bridges are not schools. This plan does not fit the topic." Which part of the case does this attack hit?

- [x] The plan
- [ ] The harm
- [ ] Solvency

**Why:** The neg reads the plan text to test topicality: does the plan fit the topic? This attack is about what the plan says, not about the problem or whether the plan works. Topicality goes on its own sheet, apart from the case.

## Two attacks on one case

The aff's case: many towns have no bus service, so people cannot get to work. The plan funds new bus routes. Solvency says new routes get people to work.

Which of these neg attacks hit solvency? Pick all that apply.

- [x] "People in those towns will not ride the bus, so the routes will not help."
- [x] "The plan pays for buses but not for drivers, so the buses will not run."
- [ ] "Only a few towns lack bus service, so the problem is small."
- [ ] "The topic is about health care, and buses are not health care."

**Why:** Both right answers say the plan will not work, so they hit solvency. "Only a few towns lack bus service" says the problem is smaller, so it hits the harm. The last answer says the plan does not fit the topic, so it hits the plan.
