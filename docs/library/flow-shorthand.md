# Flow shorthand and symbols

> **Plain version.** Flow shorthand is a set of short symbols and letters for common ideas, so you can write a whole argument in a few marks.
>
> - **Why use it:** Debate is too fast to write every word.
> - **No official list:** There is no one official list. Most debaters use the common symbols below and add their own.
> - **The key rule:** Stay the same: use the same symbol for the same idea every round.

## How to use this list

- **Learn the general symbols first.** They show up in every round.
- **Then learn the symbols for the arguments you see most.** A novice sees DAs (disadvantages) and case answers first. The theory and kritik groups can wait.
- **Make your own** for words that come up a lot on this year's topic (the resolution). Write them on a card and keep it with your flow.
- **Print this page.** Keep it in your flow folder until the symbols feel natural.
- **Look up what a term means** in the [glossary](glossary.md). This page gives only the short form.

| `X` or `/` (through a word) | no, not, does not |
| `=` | is, means |
| `≠` | is not, does not mean |
| `>` / `<` | more than, outweighs / less than |
| `w/` / `w/o` | with / without |

| `@` | at, against |

| `*` or circle | dropped, not answered |
| `SQ` or `squo` | status quo (the world now) |
| `ext` | extend (bring an argument forward) |

## Tips for writing fast

- **Drop vowels.** "Solvency" can be `Slvncy`. "Economy" can be `econ`.
- **Use the first letter for the year's topic words.** If the topic is about a program, write `P` for it, and note that on your card.
- **Use your two colors.** One for aff and one for neg. The color tells you who said it, so you do not need to write a name.
- **Leave space.** Write small and leave white space next to each argument for the answer that will come.

## Example in flow shorthand

A short DA (disadvantage) debate, written only in shorthand. On paper, each part of the DA is one row across four columns. So that it fits a phone, each row is shown here top to bottom, one speech per line.

```
DA: Spending

Row 1
1NC: U: $ tight now
2AC: 1. N/U: big bill
1AR: ext N/U
2NR: U: bill done, X new $

Row 2
1NC: L: plan -> ↑ $ 50B
2AC: 2. L/T: plan saves $
1AR: ext L/T
2NR: L/T: savings 5 yrs;
     cuts now

Row 3
1NC: IL: ↑ $ -> cuts
2AC: 3. X IL
1AR: (no answer)
2NR: Ext IL *dropped in 1AR

Row 4
1NC: I: kids lose svcs
2AC: 4. Case O/W
1AR: Case O/W
2NR: DA TC: same kids
```

*How to read it:* the neg says money is tight now (U), the plan raises costs by $50B (L), new costs force cuts (IL), and children lose services (I; `svcs` = services). The 2AC answers each part. The 1AR extends three answers but says nothing on the internal link. In the 2NR, `U: bill done, X new $` means the big bill is already passed, so there is no new money this year and uniqueness still holds. `*dropped in 1AR` marks the internal link the 1AR did not answer, and `DA TC` says the DA turns the case.

## Common mistakes

- **Changing symbols mid-season.** Fix: pick your symbols and keep them. A new symbol you forget is worse than a long word.
- **Using a symbol for two meanings.** Fix: one symbol, one meaning. If `T` is topicality, write `turn` for turns.
- **Writing only symbols, no warrants.** Fix: add two or three words for the reason ("b/c offsets").
- **Not marking drops.** Fix: use a star or circle every time an argument goes unanswered.
- **Copying someone's full list on day one.** Fix: start with the general group, then add more as you need them.
